# earshot

A terminal coding agent that listens before it acts: provider-neutral models,
deny-first permissions, explicit scope, steerable turns, append-only history,
and honest end-of-turn verification.

```bash
npm install --global @raegent/earshot
earshot doctor
earshot models
earshot
```

Requires Node 22 or newer. Full documentation, standalone binaries, source, and
security policy: [github.com/rishabhguptajs/earshot](https://github.com/rishabhguptajs/earshot).

MIT licensed. No telemetry. No subscription workarounds.
